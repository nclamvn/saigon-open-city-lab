    APIs overview

    Welcome to our API overview. You will find a brief description of the different services proposed by our APIs. Follow the links to have a more detailed description of capabilities, tutorials, technical documentation including notebooks, that will help assist you.

    APIDescription

    OneAtlas: Living Library
    The Living Library provides access to curated archive imagery from Pléiades Neo (30cm), Pléiades (50cm) as well as SPOT (1.5m) data. The associated API allows you to stream and download high-quality imagery in multiple formats. You can also use it to apply analytics on an image to count the number of vehicles or detect changes over time. Usage is based on a subscription model.

    OneAtlas: PPO ArchivesOneAtlas pay-per-order archive API allows you to browse images of a selected AOI and to order a final image product selecting a wide range of options for production and delivery. The payment of the service is calculated by order.

    OneAtlas: PPO TaskingOneAtlas pay-per-order tasking API allows you to send commands to our satellites to acquire an image over any point on Earth, during a timespan you define. You can also select tasking, delivery and production parameters. The payment of the service is calculated by order.

    OneAtlas: BasemapOneAtlas Basemap provides worldwide coverage of up-to-date imagery that can be streamed or downloaded. The API gives you access to tiles in WMTS format but you can also use GIS tools to get access the basemap. The payment of the service is calculated by order.

    RadarThe Radar API grants you access to imagery you can order and download. It allows you to send tasking commands to the satellite to fulfill your specific needs. The main assets compared to optical products are the higher precision of topography measurements. The payment of the service is calculated by order.

    WorldDEMWorldDEM (Digital Elevation Model) API allows you to download off-the-shelf imagery products with high precision elevation data. You can choose very small areas up to regional or global scale. The payment of the service is calculated by order.
