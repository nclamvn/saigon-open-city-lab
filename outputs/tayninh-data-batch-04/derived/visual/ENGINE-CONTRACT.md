## Transform QA

- Pure Python WGS84↔UTM zone 48N transform is checked against root/PROJ references.
- Root independent full-grid PROJ check: forward max error `3.651136e-7 m`; inverse four-corner max error `2.670636e-5 m`; PASS under `0.01 m`.
- `test_visual_layers.py` verifies source hashes, image sizes, full canopy grid pixel equality against TIFF, north-up orientation, true Sentinel corner references, DEM first/last UTM references, and UV grid counts.
